Créer un template web premium complet pour le secteur Agriculture, AgriTech & Cooperatives — un site React/Next.js moderne, responsive, avec design authentique et naturel.

## Stages

### Stage 1 — Créer le Design PRD (design.md)
- Palette : Vert terre (#166534) + Brun terreux (#92400E) + Or récolte (#D97706) + Blanc
- Typographie : Sans-serif naturel et chaleureux
- Mood : Naturel, authentique, terreux, innovant, durable
- Pages : Accueil, Produits, Exploitations, AgriTech, Durabilité, Coopérative, Recettes, Actualités, À Propos, Contact
- Composants réutilisables identifiés

### Stage 2 — Développement (vibecoding-webapp-swarm)
- Charger le skill vibecoding-webapp-swarm
- Générer les assets visuels (champs, récoltes, agriculteurs, technologies)
- Build complet Next.js + Tailwind CSS + shadcn/ui
- Pages publiques + espace utilisateur optionnel + espace admin optionnel
- SEO, accessibilité WCAG AA, responsive mobile-first

### Stage 3 — Polish & Deploy
- Optimisation des métadonnées SEO
- Validation responsive et accessibilité
- Déploiement
